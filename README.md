# Featured Projects

## 1. Amicus School of Engineering (Bachelor Thesis)

**Role:** Solo Developer

**Engine:** Unreal Engine 5.6

**Language:** C++

**Repository:** [BT_Inventory](https://github.com/ramagosumt/BT_Inventory)

**Source Folder:** [BT_Inventory/Source](https://github.com/ramagosumt/BT_Inventory/tree/Main/Source)

### Overview

A modular gameplay systems framework developed as my bachelor thesis project. Originally started as an inventory system prototype and expanded into a reusable architecture supporting interaction, dialogue, inventory, UI, item data, and time simulation systems.

### Technical Highlights

* Interface-driven interaction architecture
* Data-driven branching dialogue system
* Grid, List, and Slot inventory implementations
* Event-driven time simulation
* Delegate-based system communication
* Runtime UI generation
* Separation of data, objects, and world actors
* Unreal Engine C++ gameplay architecture

### Key Concepts

Gameplay Systems • OOP • Components • Interfaces • Delegates • Data-Driven Design
